## 🚀 Featured Projects

### 🛣️ [RAAHI — AI-Powered Urban Road Intelligence Platform](https://github.com/samarkumar4355/Raahi_code)
> **Computer Vision • Edge AI • Geospatial Analytics • Full-Stack Platform**

- **Overview**: An AI-powered road monitoring and civic intelligence platform that leverages transit vehicles as mobile sensing units to continuously inspect road networks.
- **Computer Vision & Edge**: Deploys YOLO object detection and OpenCV processing on-device to identify road anomalies such as potholes, surface degradation, and structural hazards in real time.
- **Geospatial Intelligence**: Associates detected anomalies with deterministic GPS telemetry, using a 10-meter Haversine spatial radius to deduplicate observations across municipal routes.
- **Full-Stack Architecture**: Features an interactive GIS dashboard with Leaflet mapping, incident audit inspection, and synchronized telemetry storage.
- **Tech Stack**: `Python`, `YOLO`, `OpenCV`, `Node.js`, `Express.js`, `MongoDB`, `React`, `SQLite`, `Leaflet GIS`
